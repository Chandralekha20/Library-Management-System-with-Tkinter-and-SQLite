# Library Management System with Tkinter and SQLite

## Project Description
This is a Python-based **Library Management System** that uses **Tkinter** for the graphical user interface (GUI) and **SQLite** for persistent storage. The system allows users to manage books in a library, including functionalities such as adding, deleting, searching, issuing, and returning books. If a book is issued, users can place a request to reserve the book in a queue.

The project demonstrates how to integrate a **GUI** with **SQLite database** to store and manage book data in a simple library system.

## Features
- **Add Book**: Add new books to the library with a unique Book ID, Title, and Author.
- **Delete Book**: Remove a book from the library by its Book ID.
- **Search Book**: Search for books based on keywords in the title or author’s name.
- **Issue Book**: Issue a book if available or add the request to a queue if the book is already issued.
- **Return Book**: Mark a book as returned and remove it from the issue status.
- **View All Books**: View the list of all books in the library, including their issue status.
- **View Request Queue**: View the request queue for books that are already issued.
